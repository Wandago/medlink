# MedLink - Healthcare & Telemedicine Connect

## Goal
MedLink connects patients with verified doctors, community healthcare workers, and local clinics for consultations, medication tracking, and emergency support—designed specifically to be lightweight, mobile-first, and responsive on slow connections.

## Steps
- [x] Create project architecture and responsive mobile-first UI layout

- [x] Build simulated Telehealth Consultation & Chat interface

## How to run it
1. Simply view `index.html` in your browser.
2. All CSS is contained in `styles.css` and logic in `app.js`. No npm or complex build step required.
