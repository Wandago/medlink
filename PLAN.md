## Goal
MedLink KE is an all-in-one platform for medical students in Kenya and worldwide to access notes, past papers, study units, and peer communities.

## Steps
- [x] Remove Country section from onboarding and automatically set to Kenya
- [x] Add extended healthcare courses (Medical Laboratory Science, Physiotherapy, Occupational Therapy, Radiography, Public Health, Community Health, Nutrition & Dietetics, Biomedical Science, Health Informatics, Health Systems, Health Economics, Epidemiology, Environmental Health, Occupational Health)
- [x] Map relevant Kenyan universities and institutions offering each course and filter them dynamically upon course selection

## What you need to do
1. Connect your Supabase and Clerk keys in `config.js` if you are using real authentication.

## How to run it
Open `index.html` in your browser or run a local static server like `npx serve .`.
