# MedLink - Healthcare & Telemedicine Connect

MedLink connects patients with verified doctors, community healthcare workers, and local clinics for consultations, medication tracking, and emergency support. Built to be lightweight, mobile-first, and responsive on low-bandwidth connections.

## Features
- **Doctor Directory**: Search and filter doctors by specialty, availability status, fee, and ratings.
- **Appointment Booking**: Schedule video, audio, text, or clinic visits with date & time selection.
- **Virtual Clinic & Triage Chat**: Interactive symptom checker and consultation console with doctor response simulation.
- **Prescription Tracker**: Track daily medications, log doses taken, and record intake instructions.
- **Emergency Hotlines & First Aid**: Direct dial buttons for ambulance/crisis support and collapsible first-aid guides.
- **Offline / Local Storage**: Appointments and prescriptions stay saved right in your browser.

## Tech Stack
- Pure HTML5, CSS3 (Modern responsive flexbox & grid design)
- Vanilla JavaScript (Zero external dependencies for rapid loading)
- Mobile-optimized typography and touch targets

## Live Preview
Simply open `index.html` in any modern web browser or mobile browser.
